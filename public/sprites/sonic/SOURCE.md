# Sonic sprite provenance

These sprites are authentic character artwork from **Sonic the Hedgehog 2**
for Sega Genesis. Sonic the Hedgehog and the original game artwork are the
property of Sega/Sonic Team; they are not original portfolio artwork and are
not covered by this repository's code license.

## Local extraction

No character pixels were rescaled, recolored, redrawn, or smoothed. The solid
cell background (`rgb(13, 72, 7)`) was made transparent and each pose was
placed on its original 48×48 crop.

- `idle.png`: source crop `59x61+23+250`, then inner crop `48x48+6+6`
- `run.png`: four Full Speed cells at y=333, size 59×61, x offsets 544,
  607, 669, and 732; each uses inner crop `48x48+6+6`
